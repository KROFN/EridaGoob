## Root cause
CONFIRMED: MakeSentientEntityEffectSystem.Effect при AllowSpeech удаляет только ReplacementAccentComponent/MonkeyAccentComponent (Content.Server/EntityEffects/Effects/MakeSentientEntityEffectSystem.cs:21-26) и не добавляет знание общего языка (LanguageKnowledge/LanguageSpeaker системы Einstein Engines, Content.Shared/_EinsteinEngines/Language/*) → впрыснутые когнизином животные продолжают говорить/понимать только "animal".

## Proposed fix (do NOT implement!)
В MakeSentientEntityEffectSystem.Effect (AllowSpeech): использовать LanguageSystem (EnsureComp<LanguageSpeakerComponent> + AddKnowledge("Common"/"Taukit")) либо добавить компонент LanguageKnowledge через AddComp с набором общих языков; синхронизировать с UpdateEntityLanguages.
