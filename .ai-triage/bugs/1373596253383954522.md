## Root cause
HYPOTHESIS (Medium): the vampire transform action spawned the form entity (PolymorphSystem.PolymorphEntity) but the mind/body replacement and original-body deletion did not complete (or the action bypassed cooldown via permissive AllowRepeatedMorphs/Cooldown config), leaving orphan PolymorphedEntity children whose Parent pointed at the still-living original; killing/eating each form then triggered Revert() on the same parent — first reverts (teleport into crit), later reverts on an already-deleted parent annihilate the character. Triggering vampire prototypes are not in this repository.
