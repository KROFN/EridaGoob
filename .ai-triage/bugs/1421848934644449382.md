## Root cause
HYPOTHESIS (средняя): (1) формула TTSSystem.AdjustVolume (база -10 дБ + GainToVolume) не обеспечивает тишину при нулевом/минимальном значении; (2) в UI Erida не найдена привязка ползунка к CCVars.TTSVolume — пользователи отключают не тот ползунок, а объявления усредняются с announcements-громкостью. Итог: полное отключение TTS недостижимо средствами настроек.

## Proposed fix (do NOT implement!)
- В TTSSystem.OnPlayTTS/PlayTTS: при `_volume <= 0` (и при обнулённом announcements) не воспроизводить звук вовсе (early return) вместо вычисления дБ.
- Добавить в AudioTab ползунки, привязанные к CCVars.TTSVolume и CCVars.AnnouncementsSound, с явной поддержкой 0 = mute.
