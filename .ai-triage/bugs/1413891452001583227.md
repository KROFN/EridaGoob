## Repository investigation
FILE: Content.Shared/SmartFridge/SharedSmartFridgeSystem.cs
SYMBOL: OnItemInserted (стр. 83) / OnItemRemoved (стр. 100) / OnRemoveEntry (стр. 172)
WHY RELEVANT: источник «памяти». OnItemInserted добавляет ключ SmartFridgeEntry(Identity.Name(...)) в Comp.Entries и в Comp.ContainedEntries. OnItemRemoved удаляет только net-uid из ContainedEntries[key], но НЕ удаляет ключ из Comp.Entries → запись с именем предмета остаётся в списке UI после изъятия.
CURRENT BEHAVIOR: запись висит в UI, пока игрок вручную не удалит её кнопкой (OnRemoveEntry доступен только когда contained.Count == 0). На момент отчёта (2025-09-06) ручного удаления не существовало вовсе.
