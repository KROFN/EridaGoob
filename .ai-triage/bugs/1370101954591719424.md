## Root cause
CONFIRMED (UI-слои): кнопки = SandboxWindow.Toggle{Light,Shadows}Button → SandboxSystem.ExecuteCommand("togglelight"/"toggleshadows") [SRC]. HYPOTHESIS (отказ, Medium): команды отфильтрованы правами — Flags: DEBUG в Resources/engineCommandPerms.yml (стр.32/34), у агост-админа без DEBUG они не выполняются; усугубляется отсутствием ресинка Pressed-состояния (SandboxUIController.EnsureWindow, TODO стр.121–126). «Агост не запускается» — не подтверждено.

1) Resources/engineCommandPerms.yml: перенести togglelight/toggleshadows из DEBUG-группы (или выдавать DEBUG флаг агост-админам) — конфиг-правка. 2) SandboxUIController.EnsureWindow: перенести синк Pressed в OnOpen и подписаться на изменения ILightManager — устранит «мгновенное выключение». 3) Добавить лог/ошибку при отказе консольной команды из UI.
