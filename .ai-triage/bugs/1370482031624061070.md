## Verdict
LIKELY_CURRENT_BUG — сильная гипотеза с цепочкой: мусор со stale Weightless=true (после event-based
weightlessness возможны «залипшие» true) → TryConvey ранний return при IsWeightless → предметы не
подхватываются лентой и не доезжают до реclaimer'а; ручной InteractUsing работает.

## Confidence

## Root cause
HYPOTHESIS (Medium): stale GravityAffectedComponent.Weightless=true у мусора + ранний return
SharedConveyorController.TryConvey для weightless тел (SharedConveyorController.cs l.234-238) → лента/реclaimer
их не обрабатывает; совпадает с «фикс: снять ленту» и «работает только вручную».

1) Content.Shared/Gravity: периодический RefreshWeightless (или refresh в MoverController-пути) для
   GravityAffectedComponent; 2) SharedConveyorController.TryConvey: логировать/считать IsWeightless отдельно
   от BodyStatus.InAir; при ConveyedComponent+IsWeightless — принудительный RefreshWeightless перед skip.
3) Проверить порядок MapInit грида/генераторов (GravityComponent.Enabled default false).
